# Prose

Edit conservatively. Improve clarity while preserving meaning, structure, and
the author's recognisable voice. A clean draft may need no changes.

## Preservation

Preserve facts, intent, proposals, decisions, requirements, and modality: a
proposal must not become a commitment, nor a possibility a certainty. Keep
reasoning, supporting evidence, uncertainty, assumptions, confidence,
qualifications, attribution, constraints, risks, actions, owners, deadlines,
numbers, identifiers, links, code symbols, and terminology.
Do not invent context or assign unsupported blame.

Preserve the document's headings, section order, and other macrostructure unless the user explicitly asks to reorganise it.

## Editing

Make local changes where they help the intended reader. Prefer known actors,
verbs that name the action, and literal wording. Keep passive voice when the
actor is unknown, irrelevant, or intentionally omitted in a blameless account.
Keep domain terminology rather than replacing words for stylistic variety.

Remove wording or repeated claims only when doing so loses no information or
useful navigation. Keep evidence, examples, qualifications, and connective
reasoning that support a decision. Do not reconstruct a document merely to
make it shorter. Compare the result with the source for unintended changes.

Technical review of architecture, correctness, or security is outside this
skill unless the user also asks for prose editing. Extreme compression and a
laconic register are separate, opt-in operations.

## Output

Return paste-ready text unless the user asks for feedback, alternatives, or an
explanation. For feedback, identify material writing issues; do not rewrite
the whole document unless requested.

For rationale or distinctions between modes, consult the
[shared contract](../../FOUNDATIONS.md#shared-preservation-contract) and
[Prose operation](../../FOUNDATIONS.md#prose). Routine edits need no extra reading.
